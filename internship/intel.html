📋 Application Process

Applications expected to open August–October 2026 on jobs.intel.com (Workday ATS). Rolling review — high-demand roles close by November 2026. Process: (1) Apply with single-column resume (Workday ATS compatibility). Apply to 5-8 positions across multiple divisions. Secure employee referral if possible (3-5x higher interview rate). (2) ATS screening filters ~60-70% based on GPA (3.0 floor), major, keyword matching. (3) Recruiter phone screen (20-30 min): qualifications, work authorization, availability, behavioral fit. (5) Virtual onsite panel (3-4 interviews, 30-60 min each via Teams): live coding/DSA, technical depth, system design, behavioral. Hardware candidates face digital design fundamentals; software candidates see LeetCode Medium with occasional Hard. (6) Offer within 3-5 business days. Average 23 days from application to offer.
